# Question-bank schema\n\nRequired: id, subject, topic, subtopic, question, option_a, option_b, option_c, option_d, correct_answer, difficulty, time_limit, explanation.\nOptional: image_url, source.\n\nValidation must reject duplicate IDs, empty questions, missing options, invalid correct answers and invalid time limits. Import must produce a row-level report before committing a versioned bank. No malformed row is silently accepted.\n
